# Tech Stack

## Backend
- **Runtime:** Node.js
- **Framework:** Express.js
- **Databases:** MongoDB (via Mongoose), SQL (via Sequelize)
- **AI Integration:** Gemini AI (@google/generative-ai)
- **Storage:** Cloudinary (for media uploads)
- **Utilities:** Multer (file handling), Sharp (image processing), Nodemailer (emails)

## Mobile App
- **Framework:** React Native (Expo)
- **UI Library:** React Native Paper
- **On-Device AI:** TensorFlow Lite (via react-native-fast-tflite)
- **Navigation:** React Navigation
- **State/Storage:** Async Storage

## Web App (Admin)
- **Framework:** React (Vite)
- **Routing:** React Router DOM
- **Analytics:** Recharts
- **UI Components:** Lucide-React (icons), React-Quill (rich text)

## Shared / Infrastructure
- **Authentication:** JWT (JSON Web Tokens), Google OAuth (google-auth-library)
- **Communication:** Axios (HTTP client)
- **Version Control:** Git
- **Development:** Concurrent execution (concurrently), Auto-reload (nodemon)
